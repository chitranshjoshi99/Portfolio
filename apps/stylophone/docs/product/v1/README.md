# Stylophone Beat Coach

An interactive, single-user app that turns a song into a **layer-by-layer play-along lesson** for the **Stylophone Beat** drum machine. Upload a clip (or paste a YouTube link), pick a ≤15s section, and the app reduces it to a playable 8-beat groove — kick/snare/hat + a monophonic bassline — mapped onto a stealth-styled **replica of the Beat** synced to a 32-step grid. You hand-correct the draft, then practice it one layer at a time. Built for the owner, first; publishable later.

**Wedge:** Stylophone **Beat** variant (not GenX1), single-user, local. One 8-beat loop = one song section. Upload + real-time guided layered play are both essential; neither is cut.
**Status:** building

## Key locked decisions (product-wide — honor in every session)

- **Tech stack:** Web — **React + TypeScript + Web Audio API via Tone.js** (transport, click, loop, cue scheduling — never hand-roll a scheduler). Vite dev server for v1.
- **Architecture:** Web UI (browser) + a **desktop-only local Python sidecar** (FastAPI) that runs **Demucs** + `reduce()`. Browser calls `http://localhost:8000`. No cloud, no accounts, no server DB.
- **Processing runs on a user-selected ≤15s loop region.** Not the whole song.
- **`reduce(clip) → draft` sits behind ONE interface** — Demucs+DSP now, on-device DSP swappable later.
- **Persistence:** `localStorage` (lessons are ~KB JSON). Export/import = download/open a `.json` file. Sync between devices = manual file transfer.
- **Deployment:** v1 = local Vite dev server + localhost sidecar (no packaging). **Electron packaging + thumbnail catalogue = v1.1.**
- **Platform reach:** Desktop-first. Build **responsive two-pane layout (CSS grid, collapsible to single-pane)** from day one so mobile polish is later config. Mobile PWA/forced-landscape/touch-tuning = fast-follow. Targets: Samsung S24+, iPhone 14+, MacBook M3+.
- **Design:** modern **stealth** (matte charcoal, greys + soft-white). **Single accent = Anthropic orange**, brightness encodes state (dim = completed layer, bright/glowing = active + "hit-now"). Circular pad preserved **exactly** (layout + native 1/1.5/2/2.5… numbering). Speaker grille → info display (BPM). Home = **instrument-first**.
- **a11y (non-negotiable):** cues never color-alone (hue + motion + shape); reduced-motion mode; contrast AA; ≥44px targets; desktop keyboard play.
- **Audio:** v1 = **ROK bank only** (drum hits + bass), sampled from the user's own hardware, shipped as static files.
- **Security:** only real surface = **validate the uploaded file** before it hits the Python subprocess (type/size/duration). No auth/network exposure otherwise (sidecar binds localhost only).
- **Legal (publish-time only, does NOT gate personal v1):** YouTube ingest (yt-dlp), redistributing sampled Beat sounds, and the Stylophone® trademark/replica are risks to resolve **before** any public release. See LB (deferred).

### The Lesson schema (v1 — the spine; do not change without a schemaVersion bump)
```json
{ "schemaVersion": 1, "id": "uuid", "title": "…",
  "source": { "type": "upload|youtube|manual", "ref": "…", "clipStart": 0, "clipEnd": 15 },
  "bpm": 120, "bank": "ROK", "bars": 2, "steps": 32,
  "layers": [
    { "id": "drums", "type": "drums", "hits":  [ { "step": 0, "sound": "kick" } ] },
    { "id": "bass",  "type": "bass",  "notes": [ { "step": 0, "pad": "1.5", "octave": 0, "length": 1 } ] }
  ],
  "teachOrder": ["drums", "bass"] }
```
`step` 0–31 (16th-note resolution over the 8-beat / 2-bar loop) · `sound` ∈ kick|snare|hat (ROK kit) · `pad` = native numbering string (1, 1.5, 2, 2.5, 3, 4, 4.5, 5, 5.5, 6, 6.5, 7) · `octave` −2..+2.
